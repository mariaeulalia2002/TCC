# Versão para Word e Google Docs

O arquivo [`template-tcc-geologia-ufsc.docx`](template-tcc-geologia-ufsc.docx) é a versão editável do modelo. Ele foi preparado em formato DOCX porque arquivos nativos do Google Docs não podem ser armazenados diretamente no Git.

## Importar no Google Docs

1. Baixe o arquivo `.docx` deste diretório.
2. No Google Drive, escolha **Novo > Upload de arquivo**.
3. Abra o arquivo enviado com o Google Docs.
4. Escolha **Arquivo > Salvar como Google Docs** para criar uma cópia nativa.
5. Atualize ou recrie o sumário automático no Google Docs.

## Regras de edição

- Preserve os estilos de título para que o sumário e a conversão para LaTeX reconheçam a hierarquia.
- Padronize os títulos numerados pela profundidade: `1` = Título 1; `1.1` = Título 2; `1.1.1` = Título 3; `1.1.1.1` = Título 4.
- Conforme o estilo do LaTeX, todos os níveis usam Times New Roman, 12 pt e cor preta. Os níveis 1 a 3 ficam em negrito; o nível 4 fica em itálico e sem negrito.
- Use o recurso de legenda para figuras e tabelas e mantenha a fonte logo abaixo de cada elemento.
- Não digite números de página manualmente no sumário.
- Não invente referências. Registre os dados bibliográficos completos e, de preferência, mantenha uma biblioteca no Zotero ou Mendeley.
- Em mapas e produtos cartográficos, informe escala, orientação, sistema de referência, datum, fonte e autoria quando aplicável.
- Ao finalizar uma etapa, exporte uma cópia em `.docx` para conversão ao projeto LaTeX.

Alguns campos automáticos do Word, especialmente sumário e numeração de páginas, podem precisar ser recriados ou atualizados depois da importação no Google Docs.
